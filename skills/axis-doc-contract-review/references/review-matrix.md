# Agreement Review Matrix

Use one record per source comment. Keep the source wording verbatim enough to identify the issue, but do not reproduce unnecessary confidential text in public reports.

## Required fields

| Field | Required content |
| --- | --- |
| Comment ID and anchor | Comment ID, point/range type, section or clause, and short anchor text |
| Original concern | The reviewer's actual concern or question |
| Value assessment | Why the concern is meaningful, partly useful, immaterial, or based on a false premise |
| Clause defect | `real`, `conditional`, `none`, or `needs facts`, with the reason kept separate from the value assessment |
| Decision | `accept`, `partially accept`, `reject`, or `needs facts` |
| Approved wording | Final replacement text, or `no change` with a concise reason |
| Modification note | What changed in scope, responsibility, procedure, remedy, timing, definition, or drafting |
| Reasoning | Contractual and operational rationale, including trade-offs |
| Legal basis | Jurisdiction, source title, provision, effective status, direct official URL, retrieval date, and supported proposition |
| Residual dependency | Missing fact, related policy, licence, product behavior, placeholder, or counsel review still required |

## Source hierarchy

Prefer current official sources in this order when applicable:

1. enacted legislation and official consolidated text;
2. binding regulation or regulator rule;
3. official court interpretation or authoritative court material;
4. regulator guidance or enforcement publication;
5. clearly labelled reviewer inference or contractual-risk allocation.

Do not cite a draft, repealed rule, news summary, law-firm article, or search-result snippet as binding authority. Secondary material may help locate a source but does not replace official verification.

## Additional full-review findings

After all original comments are covered, add a separate table for issues found during the full-document review. Use the same decision, wording, reasoning, legal-basis, and residual-dependency fields, but label the origin as `full-review finding` so it is never confused with a source comment.

## Delivery summary

The memo should close with:

- original comment count and adjudicated count;
- accepted, partially accepted, rejected, and needs-facts totals;
- additional full-review findings by severity;
- legal sources verified and review date;
- unresolved placeholders and publication blockers;
- generated file paths, page counts, comment counts, and OOXML/rendering checks;
- a scoped statement that the review does not replace qualified local counsel.
